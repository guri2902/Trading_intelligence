# Phase 25 — ML Probability Calibration + Ensemble

Adds two controls around the existing ML engine:

1. Chronological probability calibration.
2. Model ensemble weighting using validation Brier score.

The layer is advisory and cannot bypass Phase 17 signal gates or Phase 18 risk.

## Calibration
Calibration is fitted on a designated validation period only. Predictions for
future/OOS rows must be transformed with the fitted calibrator without refitting.

## Ensemble
Models are weighted inversely to validation Brier error. Current predictions
are combined with those weights. The module exposes agreement so the strategy
layer can refuse low-consensus forecasts.

## Safety
Invalid probabilities, missing validation samples, or insufficient models fail
closed. No market data or synthetic results are generated by this layer.
